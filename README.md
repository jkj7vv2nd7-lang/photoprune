# PhotoPrune

**重複・類似・ピンボケ写真をローカルAI解析し、「承認ボタン1つ」で一括自動整理＆コンテスト用ベスト作品を選出するWebアプリ**

`PhotoPrune` は、画像を外部サーバーへ一切送信せず、ブラウザ内だけで高速に写真を解析・整理できる単一HTMLアプリケーションです。Googleフォト（Google Takeout）やiCloud写真からPC・外付けSSDへ書き出した大量の写真を、手作業のストレスなく一気に片付けられます。

## 主な機能

1. **重複・類似写真の自動グルーピング（dHash 知覚ハッシュ）**  
   連写や角度違いの写真を自動グループ化し、鮮明度と解像度から「ベストショット」を自動選定。
2. **単独の失敗・不要写真検出（ピンボケ／暗所誤爆／スクショ）**  
   類似グループ以外にも、ピンボケ・真っ暗な誤爆写真・スクリーンショット候補を自動抽出。
3. **承認後ワンクリック自動隔離（`_PhotoPrune_Trash`）＆復元（Undo）**  
   PCのChrome / Edgeでフォルダを選択した場合、承認ボタンを押すだけで対象ファイルを `_PhotoPrune_Trash` サブフォルダへ自動移動します。やり直したい場合は「直前の隔離を復元」ボタンで元に戻せます。
4. **2枚同時ズーム比較（シンクロ・ルーペ）**  
   迷った2枚を並べて最大4倍まで同時ズーム＆位置合わせし、ピントや表情を瞬時に見比べられます。
5. **コンテスト応募用・ベストショット選出 TOP 3（ジャンル別審査）**  
   「総合バランス」「風景・夜景」「ポートレート」「スナップ」の4モードから100点満点で評価し、上位3作品を `_PhotoPrune_Contest_Top3` フォルダへ保存できます。
6. **撮影年月（`YYYY-MM`）別フォルダ自動仕分け**  
   残した大切な写真を撮影年月ごとのサブフォルダへ自動で整理します。

## GitHub Pages での公開方法

1. GitHub上で新しい公開リポジトリ（例：`photoprune`）を作成します。
2. 同梱の `index.html`、`README.md`、`manual.md` をリポジトリのルートにアップロードします。
3. **Settings → Pages** から Source を `Deploy from a branch`（`main` / `/ (root)`）に設定して **Save** をクリックします。
